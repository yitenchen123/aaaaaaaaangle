先说结论：ANGLE 的 Vulkan/Android 后端把 GLES 3.2 定义为 21 个必需扩展；Metal 后端目前只覆盖其中 9 个，另有 8 个可以通过 MSL 翻译 / MTL 模拟补齐。geometry shader 和 primitive bounding box 在任何 Metal 上都没有等价的硬件阶段，所以“完整 GLES 3.2”在 Metal 上不可能 100% 实现；iPhone X 还额外缺 layered rendering、多视口、gl_PrimitiveID、border color、纹理原子操作、ASTC HDR、vertex amplification 等（需要 Apple5/6/7+）。

4. 可落地路线（按光影收益排序）

第一优先：着色器存储与图像（Iris/光影直接收益）

  • SSBO：MSL 用 device T* 参数，处理 unsized array、绑定索引、graphics+compute 两侧；当前 fork 已暂时关闭 SSBO 广告，避免生成非法 MSL。
  • image load/store / atomic counter：补 argument buffer 绑定；纹理原子在 iPhone X 上用 SSBO 模拟，Apple6+ 才考虑原生纹理原子。
  • gpu_shader5 + shader_io_blocks：MSL 已支持大部分指令，翻译器需要放开并补齐 gather/bitfield/struct varying。

第二优先：纹理与帧缓冲

  • Cube map array（Apple4 支持）、2D array MSAA 纹理存储、copyImage/clearTexture、colorBufferFloat 显式广告。
  • texture border clamp：A14+ 可用 border color；iPhone X 只能对颜色采样做 shader 近似，深度/阴影不要开。

第三优先：大工程

  • Tessellation：Metal 2 有 tessellation pipeline，可翻译；工作量大，但比 geometry shader 可行。
  • Geometry shader：任何 Metal 都没有硬件阶段；compute + 间接绘制只能覆盖极少数用例，不建议承诺。
  • Primitive bounding box：无等价状态；建议永远不广告。
版本策略建议：如果目标是“光影能跑”，保留 3.2 版本号但把不支持的扩展如实报 0/不广告，让 Iris 走 fallback；如果目标是“严格 GLES 3.2 一致性”，iPhone X 必须降到 3.1，因为 layered rendering / 多视口 / gl_PrimitiveID / geometry shader / border color 在 A11 上无解。
